# Sienilampi letter

`cabin-letter.png` is the user's supplied `letter` image, copied without alteration. The same page appears on the coffee table and behind the readable letter. Narrative supplied by the user; English translation in `i18n.js` / `cabin-interior.js`.

Handwriting: Kalam Regular, by Indian Type Foundry. Original unmodified font from https://github.com/google/fonts/tree/main/ofl/kalam, distributed under SIL Open Font License 1.1. Font and license are bundled in `assets/fonts/`; no external font requests at runtime.

The letter remains rereadable and requires the existing roof/facade/yard restoration and indoor entry. It adds no inventory item or saved state. Stories are lore; this change does not alter fish size limits or add a swamp monster.
